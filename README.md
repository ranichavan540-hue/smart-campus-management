# 🎓 Smart Campus Management System

## 📌 Project Overview

Smart Campus Management System is a web-based application designed to digitally manage and simplify various campus activities. The system provides a centralized platform for students, faculty, and administrators to access and manage important academic and campus-related information.

It helps reduce manual work, improves communication, and provides easy access to campus services through a user-friendly web interface.

---

## 🎯 Objectives

- To digitize campus management activities.
- To provide a centralized platform for students and administrators.
- To manage student information efficiently.
- To provide notices and event information.
- To manage attendance and requests.
- To provide study materials and notifications.
- To provide AI-based assistance for students.
- To reduce manual paperwork and improve efficiency.

---

## ✨ Features

### 👨‍🎓 Student Features
- Student Registration and Login
- Student Dashboard
- View Notices
- View Events
- Attendance Management
- Submit Requests
- Access Study Materials
- Notifications
- AI Assistant

### 👨‍💼 Admin Features
- Admin Login
- Admin Dashboard
- Manage Students
- Manage Notices
- Manage Events
- Manage Attendance
- Manage Requests
- Manage Study Materials
- Manage Notifications

### 🤖 AI Assistant
The system also includes an AI Assistant that helps students with campus-related queries and provides intelligent assistance.
